## 🌟 أبرز الميزات والخصائص (Key Features)

### 💎 تجربة تسوق تفاعلية وفخمة
- **دعم ثنائي اللغة كامل:** واجهة عربية أصيلة مع دعم كامل للاتجاه من اليمين لليسار (RTL)، وتحويل فوري للإنجليزية (LTR).
- **محول عملات خليجي وعالمي:** دعم فوري لـ (ريال سعودي `SAR`، درهم إماراتي `AED`، دينار كويتي `KWD`، دولار أمريكي `USD`).
- **مستشار الهدايا الذكي (Smart Gift Advisor):** نظام اقتراح هدايا ذكي مبني على المناسبة والميزانية ونوع المستلم.
- **سلة تسوق وقائمة أمنيات تفاعلية:** حفظ المنتجات محلياً ومزامنة سلسة مع معالجة طلبات فورية عبر واتساب ووسائل الدفع.
- **تسليم فوري للمنتجات الرقمية:** نظام معاينة وتحميل مباشر لملفات PDF والألعاب التفاعلية وقوالب كانفا.

### 🔍 التوافق الكامل مع Google Search Console ومحركات البحث (SEO)
- **خريطة موقع قياسية (`/public/sitemap.xml`):** تشمل كافة التصنيفات، المنتجات، مقالات المدونة، والصفحات القانونية مع وسوم الصور واللغات المتعددة (`hreflang`).
- **ملف توجيه الزواحف (`/public/robots.txt`):** متوافق مع زواحف Googlebot وموجه رسمي لرابط الخريطة.
- **إثبات الملكية المسبق (Site Verification):** وسم ميتا رسمي مدمج في `<head>`.
- **بيانات منظمة غنية (Schema.org JSON-LD):** لدعم ظهور المتجر والأسعار ومربع البحث المباشر في نتائج بحث جوجل (Sitelinks Searchbox).

### 📑 الامتثال الكامل لبرنامج Google AdSense
- **ملف البائعين الرقميين (`/public/ads.txt`):** جاهز ومعتمد وفق معايير IAB.
- **شريط موافقة الكوكيز (Cookie Consent Banner):** متوافق مع سياسات الاتحاد الأوروبي وGoogle Consent Mode.
- **صفحات السياسات القانونية الشاملة:**
  - سياسة الخصوصية وملفات تعريف الارتباط (Privacy & Cookies Policy).
  - إفصاح إعلانات جوجل أدسنس الشفاف (AdSense Disclosure).
  - الشروط والأحكام وتراخيص الملفات الرقمية (Terms of Service).
  - صفحة من نحن والمصداقية (About Us - E-E-A-T Compliance).
  - صفحة اتصل بنا وخدمة العملاء (Contact & VIP Concierge).
- **قسم مدونة تحريرية أصيلة (High Quality Content):** مقالات وأدلة حصرية لتفادي رفض المحتوى الضئيل (Thin Content).

## 🚀 التشغيل والنشر السريع (Quick Start & Deployment)

### ⚡ النشر المباشر عبر Vercel (موصى به لسرعة الاستجابة العالمية)
المشروع مجهز بالكامل بملف التكوين `vercel.json` لإعادة التوجيه (SPA Routing) وتقديم ملفات `sitemap.xml` و `robots.txt` و `ads.txt` وحماية الروؤس (Security Headers):

1. ادخلي إلى حسابك في [Vercel](https://vercel.com).
2. اضغطي على **Add New...** -> **Project**.
3. اختاري مستودع GitHub الخاص بمتجر حنان (`hanan-store`).
4. سيتعرف Vercel تلقائياً على إطار العمل (**Vite**) وأمر البناء `npm run build` ومجلد المخرجات `dist`.
5. اضغطي **Deploy**.
6. **ربط الدومين المخصص (Custom Domain):**
   - من لوحة تحكم المشروع في Vercel، اذهبي إلى **Settings** -> **Domains**.
   - أضيفي النطاق: `xn--mgblao3hjb.store` (والنطاق العربي `حنان.store`).
   - قومي بضبط سجلات الـ DNS في لوحة تحكم مزود النطاق لديك (سجل A يوجه إلى عنوان IP الموضح في لوحة تحكم Vercel لديكِ مثل: `216.198.15.15` أو `76.76.21.21`، وسجل CNAME يوجه إلى: `cname.vercel-dns.com`).

### التشغيل والتطوير المحلي

### المتطلبات الأساسية
- Node.js 18+
- npm أو pnpm أو yarn

### خطوات التشغيل
1. **تثبيت الاعتماديات:**
```bash
npm install
```

2. **تشغيل خادم التطوير المحلي:**
```bash
npm run dev
```
سيكون المتجر متاحاً عبر المتصفح على: `http://localhost:3000`

3. **بناء النسخة الإنتاجية (Production Build):**
```bash
npm run build
```

4. **فحص الأخطاء البرمجية والأنماط (Linting):**
```bash
npm run lint
```
